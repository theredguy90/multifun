Sonic 2 PN Arcade

Date Added: 2021-10-21

Genres: Adventure Games, Sonic Games

Description: Sonic 2 PN Arcade is a neat Sonic The Hedgehog 2 revision that features new levels, color pallets, music, and more. This is still the beta version but it's looking good so far. This revision was created by classic sonic modder PikaNoob.

Game Controls: Enter Key = Start. Shift Key = Select. Arrow Keys = Move. Z and X Keys are action buttons. Save Progress State = [Shift+F2]. Load Progress State = [Shift+F4].
